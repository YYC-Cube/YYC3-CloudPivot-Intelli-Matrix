## 三、关键技法沉淀（可复用）

| 技法 | 场景 | 说明 |
|:---|:---|:---|
| **class stub 构造器** | `vi.stubGlobal("WebSocket"/"RTCPeerConnection")` | 箭头函数 `vi.fn(() => obj)` 无 `[[Construct]]`，`new` 时实现不执行——必须 class 形式 |
| **vi.hoisted + defineProperty 双覆盖** | jsdom 下拦截裸 `new Audio()` | 业务模块 import 提升晚于普通 stub；`vi.hoisted` 内 `defineProperty(globalThis/window, "Audio", ...)` 先于模块工厂执行才生效 |
| **src setter 宏任务触发** | 源码 `src` 赋值先于 `onerror` 挂载且无显式 `load()` | setter 内 `setTimeout(0)` 延迟读取最新 onerror，避免 metadata Promise 永挂 |
| **Object.assign 值拷贝陷阱** | FakeAudio 属性断言 | 实例属性与 proto 独立——断言读 service 持有的 `audioElement.currentTime`，非 proto 对象 |
| **真实 timers 探网络超时** | fake timers 与 jsdom 环境 setTimeout 竞态 | 改真实 timers + 极短 timeout 自然超时 |
| **--no-file-parallelism** | 本机并行 v8 覆盖率汇聚资源竞争 | 偶发 10s 超时（基线亦复现，非回归）；CI shard 模式不受影响 |
| **i18n 缺键回退断言** | `t()` 返回 key 字面量 | 直接断言中文文案（zh-CN 已补齐 pm 域全键） |
| **DOM 关系定位** | 多元素同名 | `getByText().closest("button")` + `querySelector` 精确到结构关系，避免索引脆断 |
